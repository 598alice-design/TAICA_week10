# 原始資料 04：向量資料庫與語意搜尋（Vector Search）

當所有文件段落都變成向量後，會存入專門的 **向量資料庫（Vector Database）**。這套系統讓 RAG 能夠做到「語意搜尋」，而不是傳統的「關鍵字比對」。

- **傳統關鍵字搜尋**：只看字面有沒有完全一樣。如果文件寫「筆電無法開機」，你搜「電腦沒反應」可能就找不到。
- **語意搜尋（Semantic Search）**：系統會把使用者的問題也轉成向量，然後去向量資料庫計算距離（相似度），抓出最相關的前幾名段落（例如 Top-3 或 Top-5）。

最後，系統將「使用者的問題」加上「檢索出來的 Top-K 段落」組合成一段完整的提示詞（Prompt），交給 LLM 整理出最終答案。這就是完整的「檢索 → 增強 → 生成」流程。
