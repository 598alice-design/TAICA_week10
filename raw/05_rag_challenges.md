# 原始資料 05：RAG 的常見地雷與限制

RAG 雖然能大幅降低幻覺，但它並不是萬靈丹。實務上最常遇到三個地雷：

1. **切塊不當（Bad Chunking）**：切得太碎會讓上下文斷裂（只看到數字卻不知道是哪一年的數據）；切得太大則會塞入過多雜訊，干擾模型判斷。
2. **檢索失敗（Retrieval Failure）**：俗稱「垃圾進、垃圾出（Garbage In, Garbage Out）」。如果向量搜尋沒找到正確的段落，即使 LLM 再聰明，也只能根據錯誤的參考資料作答。
3. **仍無法 100% 消除幻覺**：有時就算把正確資料放在眼前，模型還是可能誤解表格、算錯數字，或忽略參考資料而偷渡自己原本的記憶。因此設計 RAG 時，通常需要明確指示模型「若資料中沒有答案，請直接回答不知道」。
