# 向量資料庫與語意搜尋

- **一句話白話定義**：用「意思相近」而不是「字面相同」的方式，從資料庫中精準撈出最相關的參考段落。
- **核心重點**：
  1. **向量資料庫（Vector Database）**：專門儲存與比對文字向量的資料庫。
  2. **超越關鍵字比對**：即使提問用詞與文件不同（如「電腦沒反應」對應「筆電無法開機」），仍能靠語意距離找到答案。
  3. **Top-K 檢索與組裝**：取出最相關的前幾名段落，與使用者的問題打包成 Prompt 送給 LLM 生成回答。
- **生活化比喻**：跟圖書館員說「我想找讓人放鬆的書」，館員不會只找書名有「放鬆」兩字的書，而是幫你挑出療癒與冥想類的書。
